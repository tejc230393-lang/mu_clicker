# 無クリッカー

**何もしないために、何かをするゲーム。**

👉 [今すぐ無を始める](https://tejc230393-lang.github.io/mu_clicker/)

## これは何?

「無」をクリックすると、「無」が増えます。

以上です。

## 遊び方

1. 真っ白な画面を1回クリックする
2. 「無を取得しました」と言われる
3. 無をクリックする
4. 無が増える
5. 強化を買う
6. 無がもっと増える
7. 特に何も起きない
8. 4に戻る

## 機能

- **クリック強化(8種類)**
  深呼吸から「無を超えた無」まで。全部買うと1クリックで256個の無が手に入ります。256個の無とは、無です。
- **自動化(7種類)**
  無の見習い、無の住人、無の工場、無の寺院、無の惑星、無の銀河、無の宇宙。
  どれも何も作りません。ただ無が増えます。
- **無の畑**
  無を植えて、無を収穫します。種を埋めた土は無でできています。
- **黄金の無**
  ときどき画面に薄い「無」が現れます。クリックしても、半分は何も起きません。
  残りの半分は無がもらえます。たまに7倍になります。何が7倍になるのかは無です。
- **無のニュース欄**
  画面の下に、中身のないニュースが流れ続けます。
  「専門家『特に何も起きていない』」「速報:速報はありません。」
- **実績(25個)**
  すべて**特典なし**です。解除しても何も変わりません。誇りだけが手に入ります。
